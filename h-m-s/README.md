# Smart Hospital Management Platform

This repository is initialized as two separate applications:

- `frontend/`: React single page application scaffold.
- `backend/`: Node.js and Express modular API scaffold, with Prisma and PostgreSQL planned for data access.

The folders follow the supplied Smart Hospital Master Blueprint and Backend Architecture & API Learning Guide. They contain project setup and empty structure only; feature code and the Prisma data model have not been added.

Keep local secrets in `backend/.env`. The tracked `backend/.env.example` documents required settings without secret values.
